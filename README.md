# DantaMitra — Dental Care E-commerce Demo

A responsive front-end demo storefront for dental-care products.

## Included
- Responsive home page and product catalogue
- Category filters and product search
- Add-to-cart interactions, quantity controls, subtotal
- Demo checkout notice (does not collect payments)
- Mobile-friendly layout

## Run locally
1. Extract this ZIP.
2. Open `index.html` in a modern browser.

For a local development server, open this folder in VS Code and use Live Server, or run:
```bash
npx serve .
```

## Important demo notes
- Product names, prices, ratings, and artwork are sample/demo content.
- Cart state is in memory and resets when the page reloads.
- No real payments, customer accounts, order storage, inventory, or shipping integration are connected.
- Replace sample product information and contact details before presenting this as a live business.
- This project is a static front-end and does not require `npm install`.

## Deployment
You can deploy the folder using a static hosting service such as Netlify, Vercel, or GitHub Pages. Upload the project files (not just the ZIP) according to the hosting provider's instructions.
